# Custom patches

This directory is reserved for custom patch source code.

No patch implementation is included yet. Before adding code:

1. Confirm the current ReVanced patcher API and required dependencies.
2. Select a supported YouTube Music version and document it.
3. Start with one small, reversible change.
4. Add a build and test procedure so the patch can be reproduced.
5. Keep the patch's scope and limitations documented.

Do not copy proprietary YouTube Music implementation code into this repository. Follow all upstream licenses and attribution requirements for any code adapted from other projects.
